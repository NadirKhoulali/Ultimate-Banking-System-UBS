Ultimate Banking System 2.0

Build banks. Run shops. Secure vaults. Plan heists.
A connected multiplayer economy for Minecraft 1.21.1 on NeoForge.

One Economy, Built Into the World

Ultimate Banking System turns server money into a physical, player-operated economy. Accounts connect to ATMs, cards, cash, smartphones, shops, bank premises, vault storage, security systems, and multiplayer heists. The core economy is server-authoritative, while the important interactions happen through blocks, items, NPCs, and in-game applications rather than an external website.

Banking and Personal Finance

  • Checking, savings, money-market, certificate, joint, and business account workflows
  • ATMs, bank tellers, payment terminals, cards, wallets, cheques, loans, and account-specific PIN security
  • Physical USD bills, coins, cash stacks, gold bars, silver bars, and market-linked valuation
  • Transfers, payment requests, transaction history, credit information, account limits, and a movable balance HUD
  • Central Bank controls for monetary policy, reserves, and server-level banking administration

Player-Owned Banks

  • Create and manage bank premises, employees, roles, access, lending, governance, limits, and compliance
  • Configure protected vault areas, vault doors, alarms, access logs, and a live vault-storage map
  • Offer safety-deposit boxes with size-based pricing, rent, protected rows, and private viewing rooms
  • Store visible cash and precious metals in compact safes, standing safes, chests, and metal pallets
  • Inspect storage details and values without exposing private safety-deposit-box contents to bank staff

Retail and Player Shops

  • Create claimed shops with employees, permissions, opening hours, stockrooms, displays, cashiers, and terminals
  • Stock shelves and pallets, organize products, and fulfill physical delivery orders
  • Use the redesigned webshop catalog, filters, product details, cart, checkout, and order tracking
  • Show opening hours in server or client time so customers can understand the shop schedule
  • Manage shop operations through responsive desktop panels and unified tactical claim tools

Smartphone

  • Non-pausing phone overlay with a lock screen, password, themes, notifications, and configurable apps
  • Main banking app for the primary account plus separate, independently authenticated account shortcuts
  • Realtime and offline messenger with contacts, search, typing status, multiline chat, and message history
  • Send payment requests or money gifts directly inside conversations
  • Calculator, notes, paint, settings, and optional bridges for compatible map, real-estate, and auction mods

Vault Security and Access Control

  • RFID readers and cards with unique identities, access levels, card grants, attempt limits, and audit state
  • Configurable success and failure targets, signal strength, activation duration, and manual override modes
  • Per-player passage authorization for protected access points
  • Bank-premise protection against unauthorized building, breaking, projectiles, and explosions
  • Professional claim mode with private outlines, collision checks, responsive controls, and optional shared visibility

Multiplayer Bank Heists

  • Form a crew, select an eligible bank, ready up, and complete a timed server-authoritative heist
  • Use masks, lockpicks, the OVE9000 saw, RFID spoofers, thermal drills, safe drills, and computer hacks
  • Breach deposit boxes and safes, steal physical pallet contents, and load valuables into crafted duffel bags
  • React to alarms, drill stalls, tactical prompts, crew status, loot totals, and the animated extraction zone
  • Cooldown, abandonment, timeout, disconnect, crash-recovery, and server-stop safeguards restore tracked state

Built for Multiplayer Servers

  • Server configuration for economy, shops, banking, claims, smartphone behavior, security, and administration
  • Operator commands for account moderation, bank premises, shop repair, heist recovery, and diagnostics
  • Bounded transaction history to control world-data growth and reduce save-time pressure
  • Responsive desktop and phone layouts for multiple resolutions and Minecraft GUI scales
  • No embedded HTTP server, web dashboard, WebSocket server, or browser-based admin panel

Developer API 2.0

UBS exposes a documented Java API for finance, physical cash, notifications, market prices, server discovery, bank management, shop management, and heist state and actions. Add-ons can also register custom loot valuation and compatible door behavior while UBS keeps permission and validation rules authoritative.

Getting Started

  1. Install the mod on the NeoForge 1.21.1 server and connecting clients.
  2. Use /account open to create a Central Bank checking account.
  3. Use an ATM or the smartphone banking app to configure the account PIN and begin banking.
  4. Open additional accounts at player-owned banks through their bank tellers.
  5. Use the in-game owner tools and PC applications to build a bank, shop, vault, or heist target.
